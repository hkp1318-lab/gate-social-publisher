GATE CONTENT PUBLISHER

이용약관

시행일: 2026년 8월 6일

1. 목적

이 약관은 GATE 운영자가 제공하는 GATE Content Publisher(이하 “도구”)의 이용 조건과 운영 원칙을 정합니다. 도구는 GATE Blogger의 공개 글을 카드뉴스로 변환하고, 연결된 Threads 및 TikTok 계정에 게시하는 용도로 사용됩니다.

2. 이용 대상과 계정

도구는 GATE 운영자가 소유하거나 적법하게 관리 권한을 가진 계정에만 연결합니다. 다른 사람의 계정·토큰·콘텐츠를 무단으로 사용해서는 안 됩니다.

3. 콘텐츠 원칙

  • 공개 상태와 원문 제목이 확인된 GATE 글만 홍보 대상으로 사용합니다.
  • 카드뉴스와 홍보 문구는 보관된 최종 원문의 검증된 사실만 사용합니다.
  • 원문에 없는 금액·기한·자격·혜택·결과를 추가하거나 결과를 보장하지 않습니다.
  • 실제 자료가 없는 경험은 실제 체험으로 표현하지 않습니다.

4. 게시 승인과 중복 방지

외부 SNS 게시에는 프로모션 ID에 연결된 명시 승인이 필요합니다. 게시 결과는 플랫폼별 게시 ID와 상태로 확인하며, 원문 해시와 이미지 해시를 사용해 중복 게시를 차단합니다.

5. 제한과 책임

도구는 금융·보험·세금·의료·법률 또는 정부지원 결과를 보장하지 않습니다. 플랫폼 장애, 정책 변경, 심사 결과 또는 제3자 서비스의 중단으로 게시가 실패하거나 제한될 수 있습니다. 실패한 작업은 성공으로 표시하지 않습니다.

6. 외부 서비스

도구 사용에는 TikTok, Threads, Blogger, GitHub 등 외부 서비스의 약관과 정책이 함께 적용됩니다. 각 플랫폼의 이용 제한과 콘텐츠 정책을 준수해야 합니다.

7. 이용 중단과 연결 해제

계정 소유자는 언제든지 플랫폼 설정에서 앱 권한을 해제하거나 GATE 운영자에게 연결 정보 삭제를 요청할 수 있습니다. 권한이 해제되면 새 게시를 수행하지 않습니다.

8. 약관 변경

서비스 기능이나 관련 정책이 변경되면 이 페이지에 변경 내용을 공개하고 시행일을 갱신합니다.

9. 문의

약관과 앱 운영에 관한 문의는 GATE 소개 및 문의 페이지를 이용해 주세요.
